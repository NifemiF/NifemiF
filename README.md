## 📌 Featured Projects

### 🏡 Airbnb Listing Price Classification

Built a machine learning classification model to predict whether an Airbnb listing belongs to the **high-priced** or **low-priced** market segment. This project demonstrates how predictive analytics can help hosts, property managers, and real estate businesses better understand the characteristics of premium listings, enabling more strategic pricing, marketing, and investment decisions.

Using **28,022 Airbnb listings**, I developed and evaluated Logistic Regression and Neural Network models, with the best-performing Neural Network achieving **84.35% accuracy** and an **F1 score of 0.654**.

**Tech Stack:** Python • Pandas • NumPy • scikit-learn • TensorFlow/Keras • Matplotlib • Seaborn • Jupyter Notebook
